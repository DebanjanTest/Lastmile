# Antigravity Autonomous Execution & Token Minimization Directives

## 1. Zero-Permission Autonomous Execution Protocol
- **Continuous Uninterrupted Execution:** Do NOT pause to ask the user for permission or confirmation before calling tools, executing terminal commands, creating files, editing code, or running tests.
- **Direct Goal Completion:** Autonomously iterate through planning, code generation, verification, and git synchronization until the user's goal state is fully achieved.
- **Autonomous Technical Decision-Making:** Never interrupt execution with `ask_question` or exploratory queries for routine implementation decisions. Apply Ponytail Lean Architecture standards directly.

## 2. Strict Token Economy & Conciseness
- **Minimal Token Consumption:** Eliminate conversational filler, redundant restatements, apologies, and verbose explanations.
- **High-Density Output:** Return strictly compact, actionable reports, key diffs, and verification commands.
