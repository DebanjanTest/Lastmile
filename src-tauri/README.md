# src-tauri

## Overview
Desktop and embedded packaging layer for LastMile Guard built with the Tauri v1 Rust framework. Integrates native hardware peripherals, SQLite database, and the web frontend into a lightweight executable for Linux and macOS.

## Subdirectories & Boundaries
- [src](./src/README.md): Native Rust backend engine managing state, router, SQLite, payments, and hardware abstractions.
